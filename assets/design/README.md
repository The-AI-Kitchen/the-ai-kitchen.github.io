# AI Kitchen design assets

This folder contains assets for the approved Soft Panels website design.

- The session photographs are from the May 1, 2026 AI Kitchen session, credited to Miguel Ozuna / Santa Clara University on the homepage.
- `community-wall.webp` preserves the full group photo shown on slide 2 of `AI_Kitchen_ATXpo_2026_v14.pptx`. Source: the shared leadership drive's `Professional Photos/2605 UMC AI Kitchens-10.jpg`; the photo's IPTC metadata records May 1, 2026.
- `veggie-cast-transparent.png` is the six-character watercolor sprite sheet created for the website concepts with OpenAI image generation, using the AI Kitchen ATXpo deck's vegetable illustrations as references. It contains transparent padding so each chef can peek from a reserved layout cell.
- `guest-chef-hat.png` retains the chef illustration used in the presentation-based concepts.
- `ai-kitchen-mark.svg` is the site favicon using the approved green AI tile and rust chef's hat.

The official SCU logo stays at the repository root as `scu-logo-color.png`.
